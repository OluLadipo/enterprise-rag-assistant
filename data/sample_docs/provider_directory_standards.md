# Provider Directory Data Standards (Fictional Sample: Northwind Health Plan)

Every provider record must include a current address, phone number, specialty, accepting-new-patients status, and network status. Records are verified with the provider's office at least every 90 days.

A record is flagged for review when the phone number fails verification twice, when the address does not match the provider's credentialing file, or when the record has not been verified in more than 120 days.

Flagged records stay visible in the directory but display a notice that information may be outdated. Customer service representatives should confirm details with the provider's office before scheduling or sending a referral to a flagged provider.

Inaccurate directory data is a leading cause of returned referrals and member complaints. Members who report incorrect directory information should have the report logged with the category DIRECTORY_ACCURACY.
